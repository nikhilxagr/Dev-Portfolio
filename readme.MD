## 🌟 Executive Summary

This repository houses a **production-ready full-stack software engineer portfolio and services platform** built from the ground up for high performance, enterprise security, and interactive client engagement.

Far beyond a static showcase, it is an interconnected ecosystem featuring:

- 🎨 **31 Dynamic Pages & Interactive Labs** powered by React 19, Vite 8, and Tailwind CSS.
- 🤖 **Nikhil AI Assistant** — a conversational AI widget powered by Google Gemini and a custom vector-chunked RAG (Retrieval-Augmented Generation) portfolio knowledge base.
- 🏗️ **Interactive System Design Blueprints** — real-world architecture teardowns (e.g., URL Shortener / TinyURL) with interactive capacity calculators, component schematics, and trade-off analyses.
- 🧪 **Interactive DSA Lab** — live algorithm visualizers for Sorting (Quick, Merge, Heap, Bubble), Trees, Graphs, and Dynamic Programming.
- 💻 **Cyber Terminal & Security Lab** — interactive Unix-style terminal CLI with custom executables and cybersecurity tool demonstrations.
- 💳 **Production Payment Gateway** — complete Cashfree checkout workflow for booking consulting and freelance development services.
- 🧾 **Fintech Receipt Verification Portal** — self-service portal equipped with one-time password (OTP) email verification, cryptographic download tokens, PDF streaming, and direct email delivery.
- 👤 **User Community & Profile Module** — email authentication and Google OAuth 2.0, interactive profile customization with canvas avatar cropping, and user activity feeds (likes and comments).
- 💬 **Article Interaction Engine** — live community feedback with likes, view counters, and threaded comments on technical articles.
- 🔐 **Secure Admin CMS Dashboard** — protected by JWT and bcrypt, providing real-time analytics, payment tracking, contact management, and blog publishing.
- ⚡ **Ultra-Smooth 120 FPS Motion & Scroll** — Framer Motion `LazyMotion` GPU compositor variants paired with Lenis smooth scrolling that auto-pauses RAF at idle.

## 🔒 Comprehensive Security Stack

| Defense Layer | Technology | Security Enforcement |
|---|---|---|
| **HTTP Security Headers** | `helmet` | Enforces HSTS, Strict CSP, prevents MIME-sniffing, disables frame embedding |
| **Cross-Origin Resource Sharing** | `cors` | Restricts access exclusively to verified frontend origins with optional preview regex |
| **Tiered Rate Limiting** | `express-rate-limit` | Individual limiters for Auth, Contact, Payments, AI Chat, and Public reads |
| **Input Validation** | `express-validator` | Strict whitelist validation and length boundaries on all incoming request bodies |
| **NoSQL Injection Defense** | `express-mongo-sanitize` | Recursively sanitizes request objects by removing `$` and `.` operators |
| **Cross-Site Scripting (XSS)** | `xss` | Strips executable script tags and sanitizes user-submitted HTML |
| **Parameter Pollution** | `hpp` | Prevents HTTP Parameter Pollution attacks |
| **Authentication & Tokens** | `jsonwebtoken` + `bcryptjs` | Passwords hashed with cost factor 12; short-lived cryptographically signed tokens |
| **Financial Security** | Cryptographic Tokens | HMAC-SHA256 signature verification for Cashfree webhooks and OTP receipt tokens |

## ⚡ Quick Start & Development Setup

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/nikhilxagr/Devloper-Portfolio.git
cd "Devloper-Portfolio"

# Install frontend dependencies
cd frontend
npm install

# Install backend dependencies
cd ../backend
npm install
```

### 2. Configure Backend Environment

Create `backend/.env`:

```env
# Application Settings
NODE_ENV=development
PORT=5000
FRONTEND_URL=http://localhost:5173
ALLOWED_ORIGINS=http://localhost:5173

# Database Connection
MONGODB_URI=mongodb://127.0.0.1:27017/devportfolio
ALLOW_START_WITHOUT_DB=false
DB_MAX_POOL_SIZE=25
DB_MIN_POOL_SIZE=5

# Admin Credentials
JWT_SECRET=your_super_secret_jwt_key_at_least_32_chars_long
JWT_EXPIRES_IN=1d
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD_HASH=$2b$12$EXAMPLE_BCRYPT_HASH_HERE

# Google OAuth 2.0 (Optional for local dev)
GOOGLE_CLIENT_ID=your_google_client_id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your_google_client_secret
GOOGLE_CALLBACK_URL=http://localhost:5000/api/user-auth/google/callback

# Google Gemini AI Assistant
GEMINI_API_KEY=your_gemini_api_key_here

# Cashfree Payment Gateway
CASHFREE_APP_ID=your_cashfree_app_id
CASHFREE_SECRET_KEY=your_cashfree_secret_key
CASHFREE_ENVIRONMENT=sandbox
CASHFREE_WEBHOOK_SECRET=your_cashfree_webhook_secret

# Email Services (Resend or SMTP)
RESEND_API_KEY=re_your_resend_api_key
PAYMENT_FROM_EMAIL=receipts@yourdomain.com
PAYMENT_RECEIPT_TOKEN_SECRET=your_receipt_token_secret_32_chars
PAYMENT_RECEIPT_EMAIL_ENABLED=true

# SMTP Fallback
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your_email@gmail.com
SMTP_PASS=your_gmail_app_password
EMAIL_FROM="Nikhil Agrahari" <your_email@gmail.com>
```

### 3. Configure Frontend Environment

Create `frontend/.env`:

```env
VITE_API_BASE_URL=http://localhost:5000/api
VITE_SITE_URL=http://localhost:5173
```

### 4. Seed Sample Database (Optional)

```bash
cd backend
npm run seed
```

### 5. Launch Local Dev Servers

In terminal 1 (Backend):
```bash
cd backend
npm run dev
```

In terminal 2 (Frontend):
```bash
cd frontend
npm run dev
```

Visit `http://localhost:5173` to explore the full portfolio.
