# Nikhil's Projects

## 1. Developer Portfolio (This Website)

**Type**: Full-Stack Web Application  
**Status**: Live & Production  
**Live URL**: https://nikhilxagr.vercel.app

### Description
A premium, production-grade personal portfolio website that showcases Nikhil's skills, projects, journey, and services. This is not a simple static portfolio — it's a fully dynamic web application with multiple integrations.

### Key Features
- **Admin Dashboard**: Full CMS for managing projects and blogs with rich content editing
- **Payment Integration**: Real money payment gateway (Cashfree) for freelance services
- **Google OAuth**: Secure user authentication with Google Sign-In
- **Blog System**: Full-featured blog with markdown support and admin management
- **AI Assistant**: Nikhil AI — an intelligent recruiter assistant powered by Google Gemini
- **DSA Lab**: Interactive data structures and algorithms visualization
- **Terminal Emulator**: Browser-based terminal for fun interactive experiences
- **Security Labs**: Cybersecurity experiments and tools
- **Theme System**: Dark/light mode with smooth transitions

### Tech Stack
**Frontend**: React 19, Vite, Tailwind CSS, Framer Motion, React Router v7  
**Backend**: Node.js, Express 5, MongoDB, Mongoose  
**Auth**: JWT + Google OAuth 2.0  
**Payments**: Cashfree Payment Gateway  
**AI**: Google Gemini API  
**Deployment**: Vercel (frontend), Render (backend), MongoDB Atlas (database)

### Security Highlights
- Helmet.js for HTTP security headers
- Custom XSS sanitization middleware
- NoSQL injection prevention
- Rate limiting on all sensitive endpoints
- CORS policy enforcement
- JWT with bcrypt password hashing

## 2. Vistagram

**Type**: Social Media Platform (Instagram Clone)  
**Status**: Completed

### Description
Vistagram is a full-featured Instagram-inspired social media application. Users can share photos, follow each other, like and comment on posts, and explore a feed of content from people they follow.

### Key Features
- User registration and authentication
- Photo upload and sharing
- Follow/unfollow system
- Like and comment on posts
- Explore/discovery feed
- User profiles with post grids
- Real-time-style updates

### Tech Stack
React.js, Node.js, Express.js, MongoDB, Cloudinary (media), JWT Authentication
