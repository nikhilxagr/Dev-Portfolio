# Nikhil's Journey

## The Beginning

Nikhil's journey into technology began with curiosity — the desire to understand how the web works, how applications are built, and how systems can be made secure. Like many developers, he started with simple HTML pages and gradually fell in love with the craft.

What set Nikhil apart early on was his dual interest in both **building** and **breaking** — he wanted to create amazing applications AND understand how they could be attacked and defended.

## Learning Milestones

### First Steps — Web Fundamentals
- Learned HTML, CSS, and JavaScript from scratch
- Built first static websites
- Discovered the power of making things interactive with JavaScript
- Fell in love with the creative side of web development

### Going Deeper — JavaScript & React
- Mastered JavaScript ES6+ features
- Learned React.js and component-driven development
- Built dynamic single-page applications
- Discovered Vite as a superior build tool
- Learned Tailwind CSS for rapid, consistent styling

### Backend & Full-Stack
- Learned Node.js and Express.js
- Built REST APIs from scratch
- Integrated MongoDB for persistent storage
- Implemented JWT authentication and security
- Deployed first full-stack applications

### Security Journey
- Studied OWASP Top 10 vulnerabilities
- Learned secure coding practices
- Implemented security measures in personal projects
- Began studying penetration testing concepts
- Built cybersecurity tools for the portfolio

### Production Engineering
- Integrated real payment gateways (Cashfree)
- Implemented Google OAuth 2.0 authentication
- Learned deployment pipelines (Vercel + Render + Atlas)
- Built admin dashboards and CMS systems
- Developed AI-powered features using Google Gemini

## Current Chapter

Nikhil is currently focused on:
- Deepening backend and system design knowledge
- Expanding cybersecurity expertise
- Building more impactful, real-world projects
- Preparing for professional software engineering roles

## Philosophy

> "I don't just want to write code. I want to build things that matter, build them the right way, and make sure they're secure enough to trust."

Nikhil believes in:
- **Learning by building** — Real projects teach more than tutorials
- **Security first** — Never bolt security on later
- **Quality over speed** — Slow is smooth, smooth is fast
- **Continuous improvement** — Every project should be better than the last

## What's Next

Nikhil is looking to join a team where he can:
- Contribute meaningfully to real products
- Continue growing as an engineer
- Apply his security-conscious mindset
- Learn from experienced developers and mentors
